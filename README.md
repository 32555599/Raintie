## 它能记什么

- **人物档案**　姓名、电话、生日、工作、城市，加上关系、标签、备注。一个人一块地方。
- **故事与关系**　「一起看流星雨」是故事，「从朋友变恋人」是关系。两条线分开记，不会混成一团。
- **时间轴**　所有人和你之间的事，按日期从近到远排成一条流，可以按人、按类型、按年月筛选。
- **图库**　照片挂在人下面，能加标题、写描述、标收藏，还能关联到某段故事。
- **AI 辅助整理**　不内置 AI。复制提示词发给任意 AI，描述这个人，把返回的 JSON 粘回来，档案自动填好。
- **只存在你的手机里**　不联网、不注册。应用锁用数字密码或图案，回收站留 30 天，数据可以打包成 zip 备份和恢复。

还有：十几套配色（含深色）、自定义背景、信息密度可调、按姓名/拼音首字母/标签/故事内容搜索、使用统计。
